## Status values

- `awaiting intake` — client config not yet populated
- `brief in progress` — research underway, no brief file yet
- `brief ready` — brief complete, awaiting write
- `writing` — draft in progress
- `in review` — draft sent for client approval
- `published` — live, IndexNow pinged, GSC tracking
- `archived` — taken down or replaced

## How to use this register

1. New post starts → add row with status `brief in progress`
2. Brief file saved → status `brief ready`, link the brief path
3. Draft live → status `published`, fill publish date + word count
4. At 14/30/60/90 days post-publish → fill GSC position (avg position last 7 days for target query)
5. If position stalls 30+ days → schedule refresh, log `Last Refresh` date when done
