# RecruiterGTM — Keywords Bank (Informational Engine)

The master target list for recruitergtm.com — the authority/informational engine (Engine 1 in `seo-model-and-inspiration.md`). Every keyword here is a live Ahrefs pull (US, 2026-08-12), filtered to **winnable at DR 0.1** (mostly KD ≤ 10) and **relevant to our ICP** (recruitment agency owners + recruiters). The 2x/week content engine draws from this every Monday.

**Commercial "best ATS / CRM / sourcing tool" terms are deliberately excluded here** — those belong to the Pulse Recruit bank (Engine 2), built separately. A few dual-intent terms are tagged `→Pulse` where the commercial version is better hosted on the SaaS.

**Legend:** Vol = US monthly volume · KD = keyword difficulty · TP = traffic potential · Intent: I = informational, C = commercial · Tier 1 = build first (KD ≤ 5, strong fit), Tier 2 = second wave (KD 6-15), Tier 3 = long-tail/support.

**Scope note:** US data. A UK pass is pending (a chunk of our clients/proof are UK/EU) — run before finalising geo-sensitive terms.

---

## How to use this bank
1. Monday planning pulls the next 2 posts from here (Tier 1 first, then Tier 2), respecting the pillar rotation.
2. Each pillar has ONE hub (the pillar guide, 2,000+ words) + spokes. Spokes link up to the hub; the hub links down (rule D2).
3. When a term is picked, it moves into `content-register.md` with a brief. Never write without a brief.
4. Refresh existing pages before writing net-new when a page already covers the topic (rule A6).
5. Re-verify volume/KD at brief time — this snapshot ages.
