# SEO Model & Inspiration — Who's Winning This Niche and How to Copy Them

The template to model, backed by live Ahrefs data (2026-08-12) + a web-research sweep. This is the strategic answer to "who has already gotten SEO working in our niche, and how do we copy them?" Pairs with `competitor-and-backlink-research.md` (our direct competitors) and `glossary.md`.

**Verification note:** DR / traffic / keyword figures marked ✓ are live Ahrefs API pulls. Roster items without ✓ come from the web-research sweep and should be Ahrefs-confirmed before we build against them. Where the sweep and Ahrefs disagreed, Ahrefs wins.

---

## The headline finding

The business coaches in our niche (Automindz, DSP, Agency Blueprint) barely do SEO. The players actually winning recruitment-niche organic search are **software tools** running a **product-led SEO template**. That template is highly replicable, and most of its pages **rank with zero or near-zero backlinks** — which is exactly what a DR-0 site needs.

**Proof:** Happlicant (DR 24 ✓) ranks its "Bullhorn alternatives" page (1,800-vol keyword, 47 visits/mo ✓) with **0 referring domains** ✓. Recruiterflow's "bullhorn competitors" page (721 visits/mo ✓) ranks with **1 referring domain** ✓. These are bottom-funnel, low-competition, high-intent terms that rank on relevance and page quality alone.

## The three engines (from Recruiterflow, the category leader)

Recruiterflow is the aspiration model: **DR 76 ✓, 2,651 organic keywords ✓, ~28,000 visits/mo ✓, ~$77,000/mo in traffic value ✓.** It runs three engines simultaneously:

### Engine 1 — Informational authority pillars (earns links, builds DR)
High-volume TOFU guides that attract backlinks. Recruiterflow examples ✓:
- "recruitment strategies" — 15,000 vol → 6,222 visits/mo, 40 ref domains
- "interview questions to ask candidates" — 6,200 vol → 2,412 visits/mo
- "recruitment trends" — 135 ref domains
- "recruiting tools", "talent mapping", "recruiting metrics"

→ **This is RecruiterGTM's engine** (the agency/community brand). Our automation/AI/sourcing clusters live here. This engine builds the domain authority the whole network borrows.

### Engine 2 — Tool-SEO template (ranks with ~no links)
Bottom-funnel commercial pages. The replicable page types:

| Page type | Proven example | Target pattern |
|-----------|----------------|----------------|
| **Best [category] for [segment]** | happlicant `/best-ats-for-small-recruitment-companies` | "best ATS for [solo recruiters / small agencies / staffing / tech]" |
| **[Competitor] alternatives** | happlicant `/top-9-bullhorn-alternatives` | "[Bullhorn/Loxo/Greenhouse] alternatives" |
| **[Us] vs [competitor]** | happlicant `/compare/happlicant-vs-avionte` | "[competitor] vs [us]" |
| **[Competitor] pricing** | happlicant `/blog/jobadder-pricing` | "[competitor] pricing / cost" |
| **Free tools / assessment library** | happlicant `/test-library/disc-assessment` | high-vol tool/quiz terms |
| **Resource listicles** | happlicant `/top-15-recruitment-books` | "recruitment books", "linkedin post ideas for recruiters" |

→ **This is Pulse Recruit's engine** (the SaaS). It captures buy-now intent and drives product signups, and it ranks fast because it doesn't depend on DR.

### Engine 3 — Programmatic career/location pages (feature-driven, scales)
Recruiterflow hosts clients' job boards on its own domain — `/wishup/jobs`, `/coinswitch/jobs` ✓ — capturing "[company] careers" and huge job-seeker terms ("airline remote jobs", 8,200 vol ✓) for free. Every customer becomes a ranking asset. Pattern: `[role] jobs in [city]`, generated from structured data with JobPosting schema, API integration (not iframes — iframes hurt SEO).

→ **A Pulse Recruit feature-play for later** — if it hosts client career pages, each customer generates programmatic ranking pages on the Pulse Recruit domain.

## The multi-site architecture (mapped to the 5 revenue streams)

Reyhan's revenue streams — RecruiterGTM community, DFY systems agency, offshore talent + augmented teams, mastermind events, and **Pulse Recruit (SaaS)** — support a legitimate interlinking topical network:

| Property | SEO engine | Captures | Links role |
|----------|-----------|----------|-----------|
| **recruitergtm.com** (agency + community) | Engine 1 — informational authority | TOFU/MOFU: automation, AI, sourcing, content clusters | Earns the backlinks; hub of authority |
| **Pulse Recruit** (SaaS) | Engine 2 + 3 — tool-SEO template + programmatic | BOFU: "best ATS/CRM for [segment]", alternatives, vs, pricing, career pages | Ranks without links; converts to signups |
| Mastermind / event site | supporting | branded + event terms | references both |
| Talent-placement page(s) | supporting | "hire offshore GTM engineer" type terms | references both |

**How they interlink:** RecruiterGTM guides link to Pulse Recruit comparison/best-for pages (passing authority + funnelling to signups); Pulse Recruit links back to RecruiterGTM guides for depth. Every tool named uses the affiliate URL (Clay, Instantly, HeyReach, Apollo, Apify — per the affiliate rule).

**Guardrail:** this works *because every site is a real product with genuine content*. A SaaS cross-linking its parent brand is normal and safe. Do NOT build thin sites purely to pass links, keep interlinking contextual and natural — Google penalises manipulative link networks, not legitimate brand families.

## Replicable tactics, ranked for a DR-0 site

1. **"Best [category] for [segment]" listicles** — lowest competition at the segment level (KD 0-10), commercial intent, ranks with few links. Model: Happlicant's 6-tool competitive structure or Recruiterflow's 18-tool guide. Start with "best ATS for recruitment agencies / small agencies / staffing".
2. **"[Competitor] alternatives" pages** — high-intent switch searches, KD 2-4, near-zero links needed. One page per major tool (Bullhorn, Greenhouse, Loxo, Workable, JobAdder).
3. **"[Competitor] pricing" pages** — commercial intent, freshness wins (prices change), transparency builds trust. Model: ATZ CRM.
4. **"[Us] vs [competitor]" pages** — capture active evaluation searches. Model: 100hires.
5. **Topical-authority clusters on an underserved vertical** — 20-40 interlinked posts on one niche (e.g. recruiting for a specific sector) beats scattered generic posts.
6. **Free tools / templates / assessment library** — lead magnets that rank for high-volume tool terms and earn links.
7. **Programmatic career/location pages** (Engine 3) — once Pulse Recruit hosts client job boards.

Every comparison/listicle page embeds affiliate links for any third-party tool named (required per the affiliate rule) — turning content into affiliate revenue while it ranks.

## What this means for the Keywords Bank

The bank must be **split by site**, because the two engines target different intent:
- **Pulse Recruit tab** — the tool-SEO template terms (best-for / alternatives / vs / pricing / free-tool), mapped to page-type.
- **RecruiterGTM tab** — the informational clusters (automation / AI / sourcing / content / operations), mapped to pillar.

Each keyword carries: volume, KD, CPC, TP, intent, page-type, target site, and existing-page-vs-new. That is the next build.
