### B. The Engine Framework™ (course architecture)
- B1. ONE flagship course: **The RecruiterGTM System** — 5 stages, **36 core modules + 6 lettered sub-lessons = 42 lessons** (counts updated 2026-07-22 after the all-lessons-retained rebuild + topic-fit repositioning; member-facing copy says "40+ lessons", never an exact count that drifts). Per stage: S1 RecruiterOS 6 (1.1–1.5 + 1.2a) · S2 OperatorOS 13 (2.1–2.10 + 2.3a/2.4a/2.10a) · S3 OutboundOS 8 sets (3.1–3.8) · S4 TrackingOS 4 (4.1–4.4) · S5 ContentOS 11 (5.1–5.9 + 5.2a/5.4a). Plus 5 checkpoint pages, Welcome (0.1 + 0.2 MY PROFILE), 1 bonus (Operator's Library). Live map: the Course Build Map artifact + `projects/skool-courses/engine-framework-course-map.html`. The old 4 courses (OperatorOS, OutboundOS, RecruiterOS, ContentOS) are dissolved into it (mapping in `references/classroom-inventory.md`). **Engine names — every stage has one, use them in copy and videos:** Stage 1 RecruiterOS · Stage 2 OperatorOS · Stage 3 OutboundOS · **Stage 4 TrackingOS (named 2026-07-15, covers ATS + everything related)** · Stage 5 ContentOS. Old-video references to OS names are bridged in the Welcome, never re-recorded.
- B2. Every module = **WATCH** (5–8 min video) → **BUILD** → **PROVE** (deliverable verified before next module). **Coaching prompts are PER STAGE, not per module (Reyhan, 2026-07-20):** one Stage Coach prompt per pillar (5 total) + the MY PROFILE builder on the Welcome page = 6 prompts. Rationale: most new lessons already contain their own in-lesson Claude prompts; a per-module coach next to them is confusing. The Stage Coach sits on the stage opener page, runs as ONE persistent Claude conversation through the stage — after each video it directs the member to run that lesson's in-lesson prompt and bring back the output — gate-checks deliverables as it goes, adapts by desk profile, and finishes by verifying checkpoint evidence + sending the member to post in Learning Checkpoints. Later lesson pages carry only a one-liner: "continue in your Stage Coach conversation." Affiliate links embedded in coach prompts per D4. Master copies: `projects/skool-courses/module-coach-prompts/` (one file per stage), synced to Desktop per E1.
- B3. Every stage ends in an **evidence Checkpoint** — proof, never a quiz:
  - Stage 1 Productization → 🔵 **POSITIONING**: niche statement + live TAM + offer one-pager + price card + 5 testimonial asks sent
  - Stage 2 AI Layer → ⚡ **IGNITION**: Claude running w/ their context + stack connected + 2 agents scheduled. **= the 21-day guarantee moment**
  - Stage 3 Outbound → 🚀 **DRIVE**: campaign live to 500+ prospects, replies handled, ≥1 booked call
  - Stage 4 Applicant Tracking System (TrackingOS) → 🔁 **MOMENTUM**: ATS segmented, re-engagement live, lead magnet capturing, refresh agent scheduled
  - Stage 5 Content + Authority → 🏆 **OVERDRIVE**: profile rebuilt, 5 posts live, newsletter #1 sent, 1 case study published
- B4. Pass all 5 → **Engine Owner** status. **Posting is OPTIONAL (Reyhan, 2026-07-21): the coach verifies evidence and passes the member regardless — posting in Learning Checkpoints is how members get team feedback + earn the 1:1 incentive, never a requirement to pass or advance.** Checkpoint posts go in the **"Learning Checkpoints" Skool feed CATEGORY** (LIVE as of 2026-07-16 — Reyhan created it; posts earn likes → points → leaderboard). Every checkpoint slide/page tells members to include their learnings. Post shape: what I built · proof · what I learned · how it applies to my desk. **Incentive (set 2026-07-16): 3 checkpoint posts = one free 1:1 coaching session with the team** — lands at DRIVE, the natural momentum peak; does not cannibalize Accelerator (one earned session ≠ unlimited subscription). Ops: AI Guide/VA tracks post counts; at 3, team DMs the member a booking link.
- B5. The AI Guide (in-Skool, trained on course + Q&A recordings) is the gatekeeper — it asks for checkpoint evidence before building Stage N+1 with a member.
- B6. Never add/remove/renumber modules without explicit ask from Reyhan (carried from skool-classroom).
- B6b. **Video REUSE mappings are PROVISIONAL** (Reyhan caught this 2026-07-16): all old-video → new-module mappings were made from classroom PAGE TEXT (titles + descriptions), never from actual video transcripts (no Tella access). Before any reused video publishes in the new course, verify it actually teaches the lesson's bullets. Mismatch → link the video as a bonus + the topic joins the recording batch as NEW. First confirmed mismatch: RecruiterOS M4 (brand/scaling, NOT productization tiers) — module 1.2 is now a NEW recording.
- B7. **Every Module Coach prompt is recruiter-native and profile-driven.** Every member is a recruiter — coaches speak in placements, fees, splits, desks, candidates and clients, never generic B2B ("products", "leads"). Stage 1 builds MY PROFILE (desk type perm/contract/temp/exec, sectors, last 5 placements + fees, billing model, team, client sources, revenue, weekly hours) and every later coach asks the member to paste it, then adapts outputs by desk type (contract → margin/volume/MPC-availability plays · perm → retained tiers + passive-candidate nurture · exec → engaged search, milestone billing, long-cycle insight · temp → speed/reliability positioning). Set 2026-07-07 after Reyhan's review.
- B8. **Audience weighting (set 2026-07-07, revised same day):** the core audience is **solopreneur recruiters + agency owners with small teams (~80%)** — coaches and copy default to them, no mode-selection ceremony. **In-house recruiters get a light built-in translation** (parenthetical, not a parallel path): "clients"→hiring managers/stakeholders, "offer"→internal service charter (SLAs, time-to-fill, agency-spend saved), outbound→candidate + passive-talent campaigns, database→silver medalists/past applicants/alumni, content→employer brand + personal talent-magnet authority; their DRIVE checkpoint = 20+ candidate conversations + full pipeline on a live req. There is NO separate "launching a business" mode — Reyhan cut it as unnecessary. The promise holds for both: systemized, lean, efficient — time back + profitability through systems.
- B9. **Stage-homing rule (Reyhan, 2026-07-21): every module/bonus lives in the stage whose ENGINE owns its topic, regardless of which old course it came from.** Brand, content, newsletter, and authority material ALWAYS homes to Stage 5 ContentOS. Precedents: newsletter moved Stage 4 → 5 (2026-07-13); Talent Partner Brand & Scaling (old RecruiterOS M4) moved Stage 1 → Stage 5 bonus (2026-07-21 — it was wrongly parked in Stage 1 after the 1.2 mismatch just because RecruiterOS was its old course). When re-homing any orphaned recording, place it by TOPIC → stage engine, never by old-course origin. **Sharpened 2026-07-21: an old lesson that fits a module's topic becomes a lettered SUB-LESSON at that position (e.g. RecruiterOS M4 → 5.2a under Narrative & Positioning) — "bonus" is reserved for material no module owns (reading lists, resource cards). Never default a well-fitting lesson to a bonus at the end of a stage.**
- B10. **Members are coached onto PAID Claude — Pro minimum, Claude Max ideally (Reyhan, 2026-07-22).** Never frame the free tier as sufficient anywhere in course copy, coach prompts, decks, or videos ("all you need is a free Claude account" is banned). Rationale: the Stage Coaches run long build conversations, Stage 2 installs Claude Code, and the whole system assumes paid-tier capacity; Max is the recommendation for headroom.

### C. Member Journey (the converting sequence — Perzon/Hormozi)
- C1. **First 10 minutes must contain a win.** Start Here includes one instant-value action (run your first AI prompt / grab a playbook) before any "watch these 6 videos" ask.
- C2. **Day 0:** welcome DM (short template per feedback_client_dm_short_sweet) + intro-post prompt ("your niche + #1 bottleneck") — engagement from hour one.
- C3. **Annual members:** book the 1:1 Roadmap call within 48h. The Roadmap call is where the **Founding Install ($3,994 = community + Claude Code)** and relevant unlocks get pitched — upsells happen in calls, not in the feed.
- C4. **Days 1–21:** drive to ⚡ IGNITION — the activation moment AND the guarantee. A member who hits IGNITION inside 21 days has experienced the transformation promise; that's the retention event.
- C5. Weekly rhythm: 2 live Q&As + checkpoint celebrations. Every OVERDRIVE pass = case-study interview request (Adris extraction script).
- C6. Classroom display order (top to bottom): Start Here → The RecruiterGTM System → Playbooks Vault → Weekly Q&A Replays → Accelerator 🔒 → 5 service unlocks 🔒.
- C7. **Challenge cadence is MONTHLY, never weekly** (Reyhan, 2026-07-10). Two monthly mechanics run in parallel: the existing engagement award (most engaged member, activity-based) + one unique Monthly Build Challenge (output-based, theme rotates through the engines, winner judged on results — Q&A teardown + 15-min Reyhan call as the prize). Never propose weekly challenges.
